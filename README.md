## 📌 Featured Projects

### 🔹 StackPulse — Developer Talent Intelligence Platform
End-to-end data engineering pipeline on the Stack Overflow 2018 Developer Survey. Medallion architecture (Bronze → Silver → Gold) using **Informatica IICS**, **Oracle**, and a **Power BI** dashboard. Includes a **Streamlit + GPT chatbot** for natural language data querying.  
🏆 HCL Data Engineering Hackathon — Use Case 2

### 🔹 Sentiment Analysis & Sales Insights
AI-powered Streamlit dashboard analyzing counselor-student call recordings using **Whisper/Vosk** for transcription, **TF-IDF + Logistic Regression / DistilBERT** for sentiment, and **Plotly** visualizations over CRM data.  
📄 B.Tech Major Project — IMSEC, AKTU

### 🔹 OTT Movie Streaming ETL Pipeline
Full Medallion architecture pipeline for an OTT dataset using **Informatica IICS** and **Oracle** — covering ingestion, cleansing, SCD Type 2, and Gold layer aggregations.  
🏆 HCL Campus Data Engineering Showcase (4-member team)

### 🔹 Sign Language Detection
Real-time ASL detection using **MediaPipe Holistic** + **LSTM** (TensorFlow/Keras). Built a **Flask web app** with live MJPEG video stream, confidence bars, and sentence builder UI.

### 🔹 Brazilian E-Commerce ETL (Olist Dataset)
Medallion pipeline (Bronze → Silver → Gold, Star Schema) using **Informatica IDMC** + **Oracle PL/SQL**. Covers surrogate key generation, SCD Type 2, Joiner/Filter/Expression transformations.  
🏆 HCL Data Engineering Hackathon — Use Case 1
